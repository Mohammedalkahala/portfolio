The lab

An AI-run home SOC

One Dell R730 running Proxmox, carved by OPNsense into isolated office, attack and SOC networks. It behaves like a small company's environment — a domain, real endpoints, a SIEM — and it's run day to day by AI agents I built, every one read-only by default and blocked from touching a rule, a firewall or a machine without my approval.

Two loops run on it

The detection loop

A threat-intel bot surfaces a new CVE or company report. An AI agent drafts a Wazuh and Sigma rule. I review and deploy it, then attack it from Kali, Atomic Red Team or Caldera. A grading agent scores PASS or FAIL against the attack — and only then does the rule commit to GitHub, with its case, grade and git history.

The operations loop

Wazuh streams level-10+ alerts to a SOC-triage agent that posts a benign / suspicious / malicious verdict with evidence. A separate ops agent posts a plain-English health report every morning — the same thing a small-firm client would actually want to see.

The agents

Six AI agents, on a leash

Five n8n workflows — detection-engineering, SOC triage, grade & review, finalize & deploy, and a daily ops report — plus the lab-ops agent that builds and changes infrastructure. Each calls a local or hosted model, logs every tool call, and posts to its own Discord channel.

Watching the watcher

The agents are the interesting part and the dangerous part, so they run on a leash. The lab-ops agent reads every machine with no admin rights and changes things only through approved, logged paths — a firewall-apply helper, a domain-join helper, and an explicit approval prompt for anything sensitive. A root-owned guard blocks secret-printing, destructive commands and any attempt to disable logging or firewalls, and every tool call is logged to Wazuh. Wazuh has its own rules that alert when the agent acts, when the guard blocks something, and when a firewall change is applied or refused. The watcher is watched.
